Supports **Endstone 0.11.13 and BDS 1.26.52.3 x86-64** on Linux and Windows.

- Rebuilds the native inventory synchronization helper against Endstone 0.11.13's pinned SDK.
- Updates dependency bounds and checks the exact BDS executable hashes before restoring shared inventories.
- Retains the missing `endstone.level` / `endstone.inventory` import fixes, offhand/armor synchronization, legacy-lock recovery, and shutdown/crash protections.

Upgrade all servers sharing the database to Endstone 0.11.13 and BDS 1.26.52.3. Stop them, replace the old plugin wheel with **one wheel matching the server OS**, retain existing configuration and data, and restart. Linux requires glibc 2.35+.

Validation: 77 automated/database tests, plus native equipment and shutdown/recovery checks on the target runtime. See [validation](https://github.com/TheNINJALLO/endstone-inventory-share-plugin/blob/main/docs/validation-2.7.10.md) for exact artifacts and test scope.
