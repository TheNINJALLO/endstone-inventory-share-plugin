Legacy inventory locks now recover automatically when the player joins. Players previously kicked with `INV-LEGACY` no longer need an administrator to run a recovery command.

- Adopts NULL/empty-token legacy flags atomically and restores the existing saved inventory.
- Preserves token-owned sessions, including pending saves and rows with inconsistent login flags.
- Fixes a reproduced deadlock between simultaneous claims of an existing player row.
- Retains shutdown capture, durable journal recovery, handoff retries, and loading protection.

**Upgrade every server sharing the database together**, preserving plugin data and journals. Old pre-token writers do not record enough information to prove they are offline and must not run alongside this release.

Automated validation: 59 tests passed, including 23 real MariaDB cases; lint passed. Final release-wheel live acceptance is pending.
