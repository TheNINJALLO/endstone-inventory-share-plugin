Fixes inventory rollback on server stop/reboot. Bedrock can remove players before Endstone disables plugins, so the old shutdown save loop could see no players. This release snapshots inventories when `stop` arrives and flushes pending saves before exiting.

- Adds periodic saves (30 seconds by default) and durable local crash recovery.
- Orders saves and commits the final inventory together with its login-lock release.
- Prevents stale/rejected sessions and incomplete restores from overwriting inventories.
- Includes 30 passing automated tests with MariaDB integration, plus real Windows BDS stop/restart and failed-save/crash/recovery validation using a connected scripted client.

**Upgrade every server sharing the database together.** Keep the existing plugin data directory, including `pending-inventories.sqlite3`. Configure planned panel restarts to send `stop` and wait for exit. Forced termination can lose changes since the last complete snapshot.
