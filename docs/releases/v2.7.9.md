Fixes `ModuleNotFoundError: No module named endstone.level` and the corresponding missing `endstone.inventory` import during plugin loading. Location and ItemStack now resolve through Endstone's native exports.

Inventory synchronization, automatic legacy-lock recovery, and shutdown/crash protection are retained. **The native helper still requires Endstone 0.11.11 or 0.11.12 with the qualified BDS 1.26.51.1 x86-64 binary.** This import fix does not qualify Endstone 0.11.13/BDS 1.26.52 for native inventory restoration. Linux requires glibc 2.35+.

Stop all sharing servers, replace the old plugin wheel with the wheel matching the server OS, keep existing configuration and data, and restart. Install only one Inventory Share wheel per server.

Regression tests load the actual plugin entry point with each Python facade unavailable and with both unavailable, on Python 3.13. Native/database checks remain part of the tagged release workflow.
